# Nova Guide — customer-first guided experience (phase 1)

**Source branch:** `cto/customer-first-experience-20261106` (draft consolidated PR #155).  
**Status:** code committed; not independently built, browser-tested, merged, or deployed.  
**Scope:** existing Blaze Break web application, **not** a second app or a backend agent.

## What was implemented

- A customer-facing, illustrated **Nova Guide** card/dialog, based on the approved Ember palette and real Blaze Break logo.
- Exactly five small steps: Welcome, Today, Check-in, Nova, My Plan. Each step has a title, one short scripted Nova explanation, a short reason and a simple icon scene.
- Back/Next, a visible step count and progress bars, Skip/Close, Finish, and optional buttons linking to the **real** matching app tab.
- A small, dismissible **Show me around** invitation on Today. No forced or automatic guided-tour modal; after signup, the pre-existing welcome flow is left intact.
- A clearly labelled **Guide** button in the existing header. It starts on the currently visible customer page, or on Welcome for other sections.
- User-scoped, browser-local dismissal and resumable step index. Stores **no** journal, health, assessment, profile, or Nova conversation content. Storage failures degrade safely.
- Reduced-motion handling, keyboard support, focus trap, Escape, reachable close/skip buttons and scrollable content on small screens.
- The old comprehensive Walkthrough is preserved for non-customer staff roles. Entitlements, role gates, data paths, AI runtime and Firebase rules are unchanged.

## What this does NOT claim

- The current tour copy is a **pre-written Nova guide**, not generated by the AI model. It does not infer what the user feels, watch behaviour, detect inactivity or use any private context.
- This is the **first functional guided-tour version**: it uses animated icon scenes rather than a custom illustration pack or spotlight/coach marks anchored to every control.
- There are no new cloud calls, AI costs, provider secrets, data tables, or outbound analytics.
- This version is **not** production-approved.

6. In a local browser/emulator: verify no automatic popup; invite appears on Today for a new customer; dismiss persists per account; header Guide opens at the current page; skip/back/next/finish/resume; links reach real tabs; no cross-account state leakage.
7. Review at 320, 375, 390, 768 and desktop widths; both Ember themes; keyboard-only interaction, visible focus and reduced-motion settings; confirm that other on-boarding and security dialogs retain precedence.
